# Chrono Trigger Cutscene Remover ROM Hack
IPS patches for SNES Chrono Trigger to create a version of the ROM with cutscenes removed for both the US and Japanese ROMs.

The current focus is on the Any% speedrun routes and associated cutscenes. The Any% NoLSS route is done and has been successfully run on the US CSR and Any% with LSS has been tested on the Japan CSR. 

Credit to [Geiger](http://geigercount.net/crypt/) for creating Temporal Flux, the CT ROM editor used to make these hacks; and Redslash for playtesting the US CSR and porting the changes and playtesting the Japanese CSR as well as creating the original speedrun practice ROM which inspired this hack.

To use this patch you will need an unaltered Chrono Trigger SNES ROM and a patching utility such as [Lunar IPS](https://fusoya.eludevisibility.org/lips/). In Lunar IPS select `Apply IPS Patch`, then select the downloaded patch and the file to patch
> Note: Lunar IPS will overwrite the original ROM, so make a copy if you want to keep the original ROM as well.
